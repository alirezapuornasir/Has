# ریاضی‌یار ۸ — دستیار مطالعه و آزمون ریاضی هشتم

یک وب‌اپ فارسی و راست‌چین برای مرور ریاضی پایهٔ هشتم، تمرین، آزمون‌دادن و دیدن کارنامه.

## امکانات

- درس‌نامه، مفهوم‌ها، قانون‌ها، رابطه‌ها، مثال‌ها و دام‌های پرتکرار برای ۹ فصل کتاب.
- فصل‌های ۱ و ۲ با جزئیات بیشتر و بر اساس متن کتابی که در این گفت‌وگو بارگذاری شده است.
- ۷۵ سؤال تمرینی در سه قالب چهارگزینه‌ای، درست/نادرست و پاسخ کوتاه.
- پنج آزمون آماده از فصل‌های ۱ و ۲ با زمان‌سنج و تصحیح خودکار.
- آزمون‌ساز: انتخاب هر ترکیبی از فصل‌های ۱ تا ۹، تعداد سؤال، سطح و نوع سؤال.
- فلش‌کارت‌های حفظیات، ثبت موارد بلد/نیازمند مرور و ذخیرهٔ پیشرفت در همان مرورگر.
- جست‌وجو و فیلتر بانک سؤال.
- پیوند ویدیوهای آموزشی فصل‌های ۱ و ۲.
- نمایش PDF انتخاب‌شده توسط کاربر در داخل برنامه.
- قابل نصب به‌صورت PWA و قابل استفادهٔ آفلاین پس از بارگذاری اولیه از یک میزبان HTTPS یا localhost.

## اجرای سریع

1. فایل ZIP را از حالت فشرده خارج کن.
2. برای دیدن نسخهٔ ساده، `index.html` را باز کن.
3. برای فعال شدن نصب و ذخیرهٔ آفلاین، پوشه را با یک وب‌سرور محلی اجرا کن؛ برای مثال در ترمینال داخل پوشه:

   ```bash
   python -m http.server 8080
   ```

4. در مرورگر به `http://localhost:8080` برو.
5. برای نصب، از دکمهٔ «نصب» مرورگر یا دکمهٔ نصب داخل برنامه استفاده کن (در مرورگرهای سازگار).

## PDF کتاب

در برنامه از بخش «کتاب PDF» می‌توانی نسخهٔ PDF را از دستگاه انتخاب کنی. فایل PDF کتاب در ZIP قرار داده نشده است. صفحهٔ حقوق کتاب در نسخهٔ بارگذاری‌شده محدودیت استفاده و بازنشر بدون مجوز را اعلام کرده؛ بنابراین برای پخش برنامه بین دوستان، PDF را فقط در صورت داشتن مجوز توزیع به بسته اضافه کن. در صورت داشتن حق توزیع، نام فایل را `riazi8.pdf` بگذار و داخل پوشهٔ `assets` قرار بده. برنامه در حال حاضر انتخاب فایل از دستگاه را پشتیبانی می‌کند.

## دامنه و دقت محتوا

- فصل‌های ۱ و ۲: درس‌نامه و نکته‌ها با جزئیات بیشتری بر اساس فصل‌های مربوط و مرور فصل کتاب بارگذاری‌شده تدوین شده‌اند. سؤال‌های بانک تمرینی و تألیفی‌اند؛ کپی کامل تمرین‌های کتاب نیستند.
- فصل‌های ۳ تا ۹: ساختار درس‌ها و صفحه‌ها از فهرست کتاب و مهارت‌های مرور فصل گرفته شده، و برای شروع مطالعه، توضیح‌ها و سؤال‌های تمرینی تازه به آن افزوده شده‌اند. این فصل‌ها جایگزین مطالعهٔ کامل متن و شکل‌های کتاب نیستند.
- نسخهٔ ارائه‌شده ۹ فصل دارد؛ کتاب آپلودشده فصل دهم ندارد.
- لینک ویدیوها خارجی‌اند و برای پخش به اینترنت و باقی‌ماندن ویدیو روی YouTube نیاز دارند.

## حریم خصوصی و ذخیره‌سازی

هیچ حساب کاربری یا سرور ثبت نمره‌ای وجود ندارد. پیشرفت و نمره‌ها فقط در `localStorage` مرورگر همان دستگاه نگهداری می‌شوند. با پاک‌کردن داده‌های مرورگر یا استفاده از دستگاه دیگر، سوابق منتقل نمی‌شوند.

## ساختار فایل‌ها

- `index.html` — صفحهٔ اصلی
- `styles.css` — طراحی واکنش‌گرا
- `data.js` — درس‌ها، فلش‌کارت‌ها، آزمون‌ها و بانک سؤال
- `app.js` — منطق برنامه و تصحیح
- `manifest.webmanifest` و `sw.js` — نصب و کش آفلاین
- `assets/` — آیکن و تصویرهای برداری برنامه
- `راهنمای-مطالعه.md` — خلاصهٔ نکته‌ها و حفظیات
- `آزمون‌های-چاپی.md` — نسخهٔ چاپی پنج آزمون آماده
- `آزمون‌های-چاپی.html` — نسخهٔ چاپی پنج آزمون (از مرورگر گزینهٔ چاپ یا ذخیره به PDF را بزن).
